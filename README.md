# The Drifters

A static multi-page website for The Drifters DayZ faction.

## Pages

- `index.html` — Home and recruitment
- `about.html` — About the faction
- `history.html` — Interactive history dossier
- `leadership.html` — Faction leadership
- `gallery.html` — Image gallery

## Preview locally

Serve this folder with any static web server, then open its local URL in a browser. The intro video, gallery images, and poster are stored alongside the HTML files.
